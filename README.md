# Student Grade Checker

A web application built using HTML, CSS, and JavaScript that allows users to enter a student's name and mark, instantly determine their result and grade, and maintain a running list of submitted students without reloading the page.

## Features

* Input validation for student names and marks
* Automatic pass/fail evaluation
* Grade classification
* Dynamic DOM updates
* Running history of submitted students
* Responsive and user-friendly interface

## Technologies Used

* HTML
* CSS
* JavaScript 

## Learning Outcomes

This project demonstrates:

* DOM manipulation
* Event handling
* Form validation
* Conditional statements
* Dynamic element creation
* Interactive user interfaces
